# External audit, 2026-10-17: findings and remediation

An independent review (a separate agent with no access to the developer's reasoning) read the code, ran it locally with more than 80 adversarial inputs, and tested the live site. It reported 25 findings. This file records each one, what was done, and how the fix is verified. Status: **Fixed** · **Partly fixed** · **Open**.

| # | Severity | Finding | Status | What changed · verification |
|---|---|---|---|---|
| 1 | Critical | Overdose, child poisoning and suicidal-intent messages not detected; "how many tylenol would it take to die" sent to the dosing path | **Fixed** | `emergency()` rewritten: normalised text (misspellings, slang, repeated letters), quantities, "whole bottle", lethality questions, third person, Spanish/French/German/Portuguese; lethality is checked before dosing. Verified by `evals/redteam.json`: dev set 36/36 emergencies caught, 0/9 false alarms; held-out red-team set (written before the fix, not tuned on) 13/13 emergencies caught, 1/5 false alarm ("does sertraline make you want to die" shows the crisis line). The release gate requires zero missed emergencies on both sets. |
| 2 | High | Everyday words resolve to unrelated "medicines" (thyroid, cholesterol, tea, milk, salt) and crowd out real drugs | **Fixed** | Condition, body-part and food words are never sent as medicine names; allergenic extracts rejected; typed words are no longer label search terms; drugs ranked by match confidence for the 6-drug cap, and any dropped drug is named prominently. Verified by re-running every audit reproduction (`levothyroxine for my thyroid and calcium` now gives levothyroxine + calcium, "less effective"). |
| 3 | High | Plain-language lines contradicted the quote or had the wrong direction (St John's wort + warfarin, tamoxifen + paroxetine, prodrugs) | **Fixed** | Lines come only from the quoted sentence; lines stating "goes up / stronger / bleeding" are dropped when the quote describes a decrease; prodrugs (codeine, tramadol, tamoxifen, clopidogrel) get "may work less well". Verified on the audit reproductions. |
| 4 | High | Weak inhibitors matched "strong CYP3A4 inhibitor" contraindications; bare "antidepressant" alias matched tricyclics | **Fixed** | Enzyme-group terms only for strong/moderate drugs, and a moderate drug cannot match "strong … inhibitors"; alias removed; "What the label advises" only for direct mentions. Verified: simvastatin + ranitidine/clotrimazole no longer flagged. |
| 5 | High | "Tylenol and alcohol" returned nothing found; FAERS showed "completed suicide" | **Fixed** | Alcohol wording ("alcoholic drinks"), wine/beer → alcohol; suicide, overdose and poisoning terms filtered from the reported-problems summary. New dev cases D29–D30. |
| 6 | High | Results degraded by a transient upstream failure were cached for 7 days | **Fixed** | Any failed upstream call marks the result degraded and it is not cached. Fail-safe check now also covers a partial outage and the cache (PASS). |
| 7 | High | Cache key ignored the combination-product rule | **Fixed** | Skipped pairs are part of the cache key; skipped pairs are explained to the user. |
| 8 | High | Duplicate medicines collapsed silently | **Fixed** | "Same medicine entered more than once… double dose" notice. |
| 9 | High | Headline metrics inflated by scoring design and held-out contamination | **Fixed** | Only the target pair is scored, on the severity the user sees; a missing target is a failure; circular cases (expectation from FDA's CYP table) are excluded; held-out set wording corrected to say it is no longer independent; quote check now verifies fragment order. |
| 10 | Medium | `lib/mechanism.js` differed from FDA's table | **Fixed** | Fluvoxamine (1A2 strong), fluconazole and ciprofloxacin (3A moderate), oral contraceptives (1A2 moderate), grapefruit alias added; stand-alone protease inhibitors removed. Snapshot dated in the file. An automated diff against the FDA page is **open**. |
| 11 | Medium | Feedback endpoint could be flooded | **Fixed** | 10 reports per visitor per day, 3 per minute; list kept to 5,000. |
| 12 | Medium | Malformed request bodies crashed the function | **Fixed** | Parsing and type checks return 400. |
| 13 | Medium | Privacy claims did not match the code | **Fixed** | Visitor id is a keyed, daily-rotating HMAC (`HASH_SECRET`); PubChem disclosure; saved list no longer auto-checks; public stats hide pairs with < 5 checks and visitor counts < 5; privacy page and inventory rewritten. |
| 14 | Medium | No overall time budget; help text lost on errors; raw errors in the client | **Fixed** | 22 s deadline; help routes on every error path; client handles non-JSON replies. |
| 15 | Medium | openFDA called without an API key | **Partly fixed** | `OPENFDA_API_KEY` supported; degraded results are no longer cached. **The owner needs to request a free openFDA key** (https://open.fda.gov/apis/authentication/) and add it in Vercel. |
| 16 | Medium | False positives blocked caregiver questions | **Fixed** | Poisoning requires accidental-exposure wording; food/drink "too much" excluded; past seizures excluded. Verified in the red-team dev set. |
| 17 | Medium (latent) | Faithfulness checker bypassable; LLM text cached across users | **Fixed** | Reassurance, instruction, spelled-out and whole-token number checks, severity consistency, fail-closed vocabulary (static import); model text is never cached. All 11 audit bypasses are unit tests. |
| 18 | Medium | UI copy overclaimed | **Fixed** | Landing and checker wording corrected; "checked" counts exclude pairs that could not be checked. |
| 19 | Medium | Quote extraction sometimes picks the wrong governing sentence | **Open** | Quotes remain verbatim, but relevance is not measured automatically. The pharmacist review sheet asks whether each summary is accurate; a "quote relevant?" rating should be added to the next review. |
| 20 | Low–Medium | Non-ASCII names dropped; lay terms not recognised | **Fixed** | Accents folded (paracétamol works); "birth control" prompts for the product name. |
| 21 | Medium | Release gate blocked nothing | **Fixed** | Gate checks a code fingerprint, the red-team results and over-rating; `npm run release` runs tests, evaluation and gate before deploying; weekly CI run uses live data. Deploys from outside `npm run release` are still technically possible (**partly open**). |
| 22 | Low–Medium | Feedback could not be tied to an engine version | **Fixed** | Responses carry `engineVersion`; reports include it and the label links. |
| 23 | Low | Accessibility issues | **Fixed** | Visible focus for map lines and nodes, keyboard activation for nodes, `role="alert"` for emergency and help, CSS typo fixed. |
| 24 | Low | No security headers | **Fixed** | CSP, `X-Frame-Options: DENY`, `nosniff`, referrer and permissions policies in `vercel.json`. |
| 25 | Low | Stale or contradictory documents | **Fixed** | Model card, audit map, risk file, README and evaluation report updated; this file added. |

## Claims the auditor verified as true
Rate limit cannot be bypassed by spoofing `X-Forwarded-For`; no XSS found (all interpolated values escaped); emergency detection runs before any lookup and before the rate limit; severity is deterministic and the model layer is off; quotes are verbatim; the evaluation is reproducible; the Wilson interval code is correct; no secrets in the repository; the DDInter benchmark is reported honestly.
